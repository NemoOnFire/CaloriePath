What is an ideal weight?

An ideal or reference weight calculator provides an estimated weight range or reference point based on height. It should not be treated as a required or medically ideal weight for every person.

About the Devine formula

The Devine formula estimates reference body weight using height and sex. For adults above 5 feet, additional weight is added for each inch above 60 inches.

Why is this only a reference?

Healthy body weight can vary considerably based on muscle mass, body composition, age, and other individual factors. Use this result as a general reference rather than an exact target.

Understanding Reference Weight

An ideal or reference weight calculator provides an estimated weight based on height. These estimates are useful as general reference points and should not be treated as a required weight for every person.

How is ideal weight calculated?

CaloriePath uses the Devine formula to estimate reference weight from your height and sex. The formula adds a specified amount of weight for each inch above 5 feet.

Why can healthy weight vary?

Healthy body weight can vary based on muscle mass, body composition, age, and other individual factors. A single formula cannot account for all of these differences.

Frequently Asked Questions

What is the ideal weight for my height?

The answer depends on several individual factors. This calculator provides a reference estimate based on the Devine formula rather than a guaranteed ideal weight.

What is the Devine formula?

The Devine formula is a commonly used equation for estimating reference body weight from height and sex.

How accurate is an ideal weight calculator?

An ideal weight calculator provides an estimate. Actual healthy weight can vary considerably between people with the same height.

Can I use ideal weight for a weight-loss goal?

A reference weight can provide context, but weight-loss goals should also consider your overall health, body composition, activity level, and personal circumstances.
